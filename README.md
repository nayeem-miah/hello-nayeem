## 🚀 Quick Start

Run directly in your terminal — **no installation needed!**

```bash
npx hello-nayeem
```

---

## ✨ Features

| Key | Feature |
|-----|---------|
| `↑` `↓` | Arrow key navigation through menu |
| `1`–`8` | Direct jump to any section |
| `Enter` | Open selected section |
| `/` | Real-time search & filter sections |
| `c` | Contact form — send a message directly |
| `m` | 🔐 Password-protected inbox (owner only) |
| `0` / `q` | Exit |

## 🛠 Built With

- **Node.js** — Runtime (no external dependencies!)
- **ANSI escape codes** — Terminal colors & styling
- **crypto** (built-in) — SHA-256 password hashing
- **readline** (built-in) — Raw mode keyboard input
- **fs** (built-in) — Message storage

---

## 🔐 Security

- Contact form messages are saved **locally** on the portfolio owner's machine
- Inbox is **password-protected** with SHA-256 hashing
- 3-attempt lockout on wrong password
